# Random Box Loot — NeoForge 1.20.1

将原版箱子首次开启变成不可跳过的逐项抽奖动画：普通/稀有/史诗/传说/绝世五档，概率 50/30/12/6.5/1.5%，物品数 3/4/5/6/8，品质提高权重。默认内置地牢战利品示例，并保留扩展表的入口。

## 构建
需要 JDK 17、联网环境：`./gradlew build`。开发运行：`./gradlew runClient`。

## 指令
- `/RandomBox SetNewBox <坐标> <品质 0-5> <战利品表名>`：生成并配置箱子（品质 0 使用随机档位）
- `/RandomBox GUI`：打开编辑器入口（当前版本提示配置位置；表格数据可在 `LootManager` 中扩展）

实现说明：首次右键会取消原版容器打开，服务器按平均 1.2 秒、±50% 的间隔逐个写入物品；期间再次交互被拦截。箱子以对应稀有度颜色的末地烛粒子环绕。已开启标记写入箱子 NBT，重启后保留。
