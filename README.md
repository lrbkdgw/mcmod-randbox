# Loot Roulette / 战利品轮盘

适用于 **Minecraft Java 1.20.1 + NeoForge 47.1.106** 的服务端权威战利品抽奖模组。

## 功能

- 玩家第一次开启带原生/数据包战利品表的容器时，不再立刻显示容器，而是播放 6 秒不可跳过的多列抽奖动画。
- 原容器的 `LootTable` 会被保存并用于生成奖品；不同遗迹、地牢与其他模组的战利品表仍然有效。
- 每个战利品容器在玩家靠近时只随机一次稀有度，并随区块永久保存：

| 稀有度 | 概率 | 非空物品栏数 | 环绕粒子 |
|---|---:|---:|---|
| 普通 | 50% | 5 | 白 |
| 稀有 | 30% | 6 | 绿 |
| 史诗 | 12% | 7 | 紫 |
| 传说 | 6.5% | 8 | 黄 |
| 绝世 | 1.5% | 9 | 红 |

- 未开启容器在玩家靠近后显示额外的末地烛光柱；开启后仍保留对应颜色的环绕粒子。
- 抽奖由服务端计时并最终写入容器。即使客户端尝试关掉界面，也不会提前获得或打开战利品。
- 支持所有继承 `RandomizableContainerBlockEntity` 且拥有战利品表的方块容器（原版箱子、木桶、潜影盒以及采用同一标准的模组容器）。普通玩家放置、没有战利品表的箱子不会受影响。

## 战利品箱调试棒

物品 ID：`lootroulette:loot_debug_stick`。可在“工具与实用物品”创造模式标签页中取得，也提供合成配方。

1. 手持调试棒，**潜行 + 左键方块**：在普通 → 稀有 → 史诗 → 传说 → 绝世之间切换。
2. 手持调试棒，**潜行 + 右键战利品容器**：清空容器、恢复它最初的战利品表，并设置为当前稀有度。

调试棒只能重置已经记录原始战利品表的容器；不会凭空给普通箱子添加战利品表。

## 构建

需要 JDK 17。项目使用 NeoForge 官方 1.20.1 legacy MDK/ModDevGradle 配置：

```bash
./gradlew build
```

成品位于 `build/libs/lootroulette-1.0.0.jar`。开发运行：

```bash
./gradlew runClient
# 或
./gradlew runServer
```

## 实现说明

- 稀有度与原始战利品表写入方块实体的 Forge persistent data，随世界保存。
- 服务端重复调用容器原战利品表以保证目标数量的非空物品栏；物品种类、NBT、附魔和堆叠数均来自该表。
- 活跃抽奖期间容器被锁定且不能破坏；计时结束后服务端写入奖品并打开原版容器菜单。
- 多人同时点击同一容器时只有第一个抽奖会话生效。
